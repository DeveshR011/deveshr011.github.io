# devesh.rawat

Personal portfolio site. Plain HTML, CSS, and JS — no build step, no framework.

Self-hosted [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) and
[IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) (SIL Open Font License)
live under `assets/fonts/`.

## Local preview

```
python -m http.server 8080
```

Then open `http://localhost:8080`.
